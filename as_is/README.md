## Компания «Медикаменте».

- операции с данными вручную
  - Журналы приёма пациентов, учёт пациентов и платежей, медицинские карты, учёт анализов ― в файлах Excel или хранят в виде сканов.
  - Учёт денежных средств — в «1С:Бухгалтерия предприятия»
  - Учёт товарно-материальных ценностей (ТМЦ) — в «1С:Торговля и склад»


- ожидание
  - открытие новых филиалов
  - автоматизация работы
  - усиление безопасности данных (медицинские карты - конфиденциальные данные)
  - уйти от ручной записи на единую систему хранения


- проблемы
  - компания не отвечает требованиям законодательства по конфиденциальным данным
  - снизить риски утечки данных
  - парадигма хранения и учета конфиденциальных данных


- принципы работы с данными
  - сбор данных
    - персональные данные - Ф. И. О., дата рождения, телефон и электронная почта
    - расширенные - адрес прописки, место работы или учёбы, хронические заболевания.
  - хранение
    - Excel, JPG и PDF.
    - данные лежат на общем сервере
    - нет контроля, аудита потоков данных


- цели
  - Интеграция лаборатории анализов с API.
    - Ограничение доступа, сокрытие данных. 
    - Использование одних и тех же для разных целей без валидации
  - использование ML, AI, BI
    - в компании есть много накопленных данных
  - системы
    - портал для клиентов
    - портал для сотрудников ресепшена
    - платежный шлюз
    - CRM для сбора данных о клиентах
    - интеграция с лабораторией анализов
  - MVP - пару месяцев
    - запись клиента к специалисту
    - ресепшен может видеть и отследить запись в системе
    - роли, доступы RBAC, ABAC
  - Финал - через год
    - полностью автоматический процесс записи через портал и мобильное приложение
    - оповещения клиенту, подтверждения клиентом
    - просмотр клиентом своих данных
    - тегирование данных в системе для защиты
    - оповещение команде при несанкционированном доступе
  - учесть
    - безопасность
    - масштабируемость
    - сопровождаемость
    - конфигурируемость


- Вывод
  - система нарушает
    - Privacy by Design
    - Перемещение данных (Data Lineage) 
    - Не учитывается минимизация данных (Data Minimization)
    - 152 ФЗ
    - доступы и роли к данным
